### 🍽️ Zomato Data + AI Platform
**Cloud ELT Pipeline with GenAI Analytics**

A data and AI platform built around approximately **10 million orders**, **23 million order items** and seven datasets (~2.2 GB), turning raw food-delivery data into analytics that can be explored using natural language.

- Built an S3 data lake and loaded seven CSV datasets into Snowflake RAW tables using external stages and `COPY INTO`.
- Developed a dbt model with seven staging models, four dimensions, two fact tables and four business marts.
- Orchestrated daily ingestion, dbt transformations and LLM review enrichment using Apache Airflow 3 and Docker Compose.
- Used an OpenAI LLM to structure customer reviews into sentiment, topic and key-issue fields.
- Built a review-based RAG chatbot with Cohere embeddings, semantic retrieval and Groq answer generation.
- Developed Text-to-SQL analytics with SELECT-only validation and a restricted Snowflake role.

**Stack:** AWS S3 · Snowflake · dbt · Airflow · Docker · OpenAI · Cohere · Groq · Streamlit

### ☁️ YouTube Trending Data Pipeline
**AWS Medallion Architecture**

An AWS-based data pipeline that ingests YouTube trending data and transforms it into analytics-ready datasets using a Bronze → Silver → Gold architecture.

- Ingested YouTube API data through AWS Lambda and EventBridge, alongside historical Kaggle data, into the S3 Bronze layer.
- Used AWS Glue and PySpark to clean, deduplicate and calculate engagement metrics.
- Stored transformed datasets as partitioned Parquet in the Silver and Gold layers.
- Implemented a Lambda-based data-quality gate with SNS failure alerts.
- Orchestrated workflow branches, retries and dependencies using AWS Step Functions.
- Queried Gold datasets through Athena and built analytics in QuickSight.

**Stack:** Python · PySpark · S3 · Lambda · Glue · Step Functions · EventBridge · Athena · QuickSight · SNS · IAM

[**View project repository →**](https://github.com/Vishnudharshan-33/yt-data-pipeline-aws-project)

### 🧠 DocMind — Real-Time Agentic RAG Assistant
**Hybrid Retrieval · Agentic Routing · MCP**

An agentic RAG system that ingests PDFs, URLs and public GitHub repositories, retrieves relevant context and can use live web search when local documents are insufficient.

- Built query routing and orchestration with LangGraph.
- Combined dense Qdrant retrieval and BM25 keyword search using Reciprocal Rank Fusion.
- Added Cohere reranking and Groq → OpenAI model failover.
- Implemented prompt-injection checks, conversation-aware follow-ups and answer self-verification.
- Exposed the system through FastAPI, a Streamlit interface and an MCP server for Claude Desktop.
- Included a RAGAS evaluation harness for faithfulness, answer relevancy and context precision.

**Stack:** Python · LangGraph · LangChain · Qdrant · BM25 · Cohere · Groq · OpenAI · FastAPI · Streamlit · MCP

[**View project repository →**](https://github.com/Vishnudharshan-33/DocMind-RAG)

### 🤖 Personal AI Agent
**Telegram Assistant · 13 MCP Servers · Dual Memory**

A personal AI assistant accessed through a Telegram bot. It accepts text and voice messages, plans tasks, calls connected tools and maintains both conversation-level and long-term memory.

- Built the agent loop with LangGraph `create_react_agent` and MCP tool adapters.
- Connected 13 MCP servers, including filesystem, browser, GitHub, Notion, Gmail, Google Calendar, Spotify, web search, reminders and YouTube.
- Added an OpenAI → Groq → OpenRouter model fallback chain.
- Used SQLite checkpointing for short-term conversation memory and mem0 for long-term semantic memory.
- Added local voice transcription with faster-whisper.
- Included prompt-level guardrails for prompt injection, action scope, secret redaction and safer handling of ambiguous requests.

**Stack:** Python · LangGraph · LangChain · MCP · Telegram · OpenAI · Groq · OpenRouter · SQLite · mem0 · faster-whisper
